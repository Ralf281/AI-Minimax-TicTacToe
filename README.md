# Trips-traps-trull Minimax-algoritmiga

Pythonis loodud käsureal töötav trips-traps-trull, kus mängija mängib arvuti vastu.

## Funktsioonid

* Mängija saab valida mängulaual käigu.
* Programm kontrollib võitu ja viiki.
* Arvuti kasutab Minimax-algoritmi.
* Programm kontrollib vigaseid ja hõivatud käike.

## Kasutatud tehnoloogia

* Python
* Minimax-algoritm
* ChatGPT tehisaru abil programmi arendamine

## Käivitamine

Käivita fail `main.py` Pythoniga:

```bash
python main.py
```
